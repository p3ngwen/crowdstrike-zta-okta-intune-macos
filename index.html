Deployment steps

1

Verify your Falcon sensor is generating ZTA data

Run this on a test Mac. If the directory or data.zta file is missing, ZTA is not enabled on your CrowdStrike tenant for macOS — contact CrowdStrike Support to enable it before proceeding.

2

Add CrowdStrike integration in Okta

Okta Admin Console → Security → Device integrations → Endpoint security → Add → CrowdStrike. Select macOS as a target platform.

3

Upload both generated profiles to Intune

For each file: Devices → Configuration → Create → macOS → Templates → Custom. Set deployment channel to Device channel. Assign to your macOS device group.

4

Ensure your Falcon MDM profile has AllowUserOverrides set to false

If AllowUserOverrides is true in your System Extensions payload, the Falcon extension can be unloaded and data.zta will stop being written. Set it to false.

5

Sync and reboot

Force a sync from Company Portal. A reboot may be required for the profiles to take full effect.

6

Test with a FastPass login

ZTA scores are only transmitted on FastPass (phishing-resistant) authentication — not password + TOTP. Authenticate via Okta Verify biometric and check the Okta System Log.
